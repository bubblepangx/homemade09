# 미장동 장례식장 신축 — 3D 조감도

전북특별자치도 군산시 미장동 58-45 외 3필지 (58-54, 58-83, 59-43) / 허가용

제출 도면(배치도 1/500, 각 층 평면도·입면도 1/150)의 **실제 치수 비율 그대로** 3D 모델을
세우고, 상·하·좌·우 4방향 조감도 + 상부 배치 조감도를 렌더링한 결과입니다.
AI 이미지 생성이 아니라 도면 치수를 좌표로 입력해 만든 형상이므로 비율이 도면과 일치합니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 브라우저에서 여는 인터랙티브 3D 뷰어 (드래그 회전 / 휠 줌 / 5개 뷰 버튼) |
| `scene.js` | 치수·재료·배치가 모두 들어있는 모델 소스 |
| `renders/front.jpg` | 정면(35M 도로측) 조감도 |
| `renders/back.jpg` | 배면 조감도 |
| `renders/left.jpg` | 좌측면(정원측) 조감도 |
| `renders/right.jpg` | 우측면 조감도 |
| `renders/top.jpg` | 상부(배치) 조감도 — 도로·주차장·정원 전체 |

## 도면에서 읽은 치수 (모델 입력값)

### 평면
| 항목 | 치수 |
|---|---|
| 건물 장변 (X) | **34,500** = 8,000+8,000+6,000+6,000+6,500 |
| 건물 단변 (Z) | **23,000** = 3,500+2,500+3,000+3,000+11,000 |
| 2층 서측 옥상 테라스 | 폭 **4,000** (2층 본체 30,500) |
| 코어(계단실·EV·W/C) | X 28,000~34,500 (6,500) |
| 옥탑(계단실+EV+기계실&물탱크실) | 6,500 × 12,000 (3,500+2,500+6,000) |

### 높이 — 입면도 1/150 실측 환산
| 레벨 | 높이 |
|---|---|
| 1층 슬래브 상단 | +5,400 |
| 1층 상부 금속 띠(캐노피 라인) | +5,400 ~ +5,900 |
| 2층 슬래브 상단 = 옥상 바닥 | +10,200 |
| 2층 파라펫 상단 | +10,900 |
| 옥탑 상단 | +13,400 |

> 입면도에 수직 치수선이 없어 1/150 축척으로 실측 환산했습니다.
> 실제 층고가 확정되면 `scene.js` 상단 `B` 객체의 `H1 / H2 / PAR / PH` 값만 고치면
> 전체 모델과 조감도가 그대로 갱신됩니다.

## 외장 재료 (요청 반영)

- **인조 화강석** — 정면 좌측 계단실 코어. 지상~옥탑 전(全) 높이 볼륨으로 처리
- **회색 벽돌** — 1층 우측(정면도 기준) = 평면 X 0~16,500 구간
- **외장 타일** — 2층·옥탑 전체 (입면도의 타일 그리드 반영)
- **유리 난간** — 옥상 상부 난간 및 2층 테라스 난간
- 금속 띠 — 1층 상부 캐노피 라인, 2층 파라펫

## 대지 형상 (배치도 치수체인 복원)

배치도의 치수 체인을 좌표로 환산해 **실제 필지 윤곽**을 세웠습니다. 세 방향 치수가
모두 맞아떨어집니다.

| 도면 치수 | 복원 좌표 | 의미 |
|---|---|---|
| 상단 8,591 / 23,000 / 110,684 | Z = −8.6 · 건물 · 동측 장변 110.7 | 북측 경계 |
| 좌측 10,089 / 34,500 / 10,446 | X = +44.6 · 건물 · X = −10.4 | 건물 양측 이격 |
| 하단 3,961 / 23,000 / 2,136 | Z = −4.0 · 건물 · Z = +25.1 | 남측 경계 |

- 전면부는 **35M 도로경계에 약 42° 사선**인 삼각형이며, 서측 첨단부가 도로 쪽으로 뻗습니다.
- 배면은 **폭 약 29m × 길이 110.7m**의 장방형 띠입니다.
- 건물은 정면(34,500 면)이 도로를 향하도록 앉히고, 이격은 도면대로 좌 10,446 / 우 10,089 /
  배면 2,136 입니다.

## 배치 · 외부

- **35M 도로** — 대지 전면에 사선으로 접합. 진·출입구 2개소
- **강변로 · 산책로 · 경포천** — 35M 도로 건너, 정면에서 보아 우측
- **주차 22면** — 서측 6면 · 전면 6면 · 후면 8면 + 장애인 2면 (배치도 3개소 위치 반영)
- **전면 정원** — 도로경계선에 정렬한 정적 수경(반사 연못 18.0m × 5.0m) + 디딤석 +
  정형 헤지 + 파고라 + 대칭 식재의 호텔형 조경. 삼각형 전면부 형상에 맞춰 도로와 평행하게 구성
- **구내 동선** — 건물 4면을 도는 순환로, 주출입 광장·드롭오프, 좌측면 발인 동선

### 전 / 답 제외
배면 장방형 띠의 안쪽 약 35m까지만 조성(후면 주차·녹지)하고, **그 너머는 전/답으로 보아
조성 대상에서 제외**했습니다. 조감도에서는 이랑 질감으로 구분해 표현했습니다.
설계된 것 외의 인접 건물은 넣지 않았습니다.
